# Курсовая работа: Получение данных о вакансиях с hh.ru

## Описание
Проект получает данные о компаниях и вакансиях с сайта hh.ru через публичный API, 
сохраняет их в базу данных PostgreSQL и предоставляет интерфейс для работы с этими данными.

## Структура проекта
- `main.py` — точка входа
- `config.py` — настройки подключения к БД и список компаний
- `src/api_hh.py` — работа с API hh.ru
- `src/database.py` — создание БД и таблиц
- `src/db_manager.py` — класс DBManager для работы с БД
- `src/user_interaction.py` — интерфейс пользователя
