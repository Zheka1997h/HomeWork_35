# Проект шифрования карты 
Этот проект представляет собой простую модель шифровки карты для простых пользователей.
Модель использует простые модули реализации данных алгоритмов.
## Установка
1.  Клонируйте репозиторий:
    ```bash
    git clone github.com/Zheka1997h/HomeWork_35/pull/1#issue-4534818177
    ```
2.  Создайте и активируйте виртуальное окружение:
    ```bash
    python -m venv venv
    source venv/bin/activate
    ```
3.  Установите необходимые библиотеки:
    ```bash
    pip install -r requirements.txt
    ```
   
## Структура проекта
-   `_init_ `: Исходная инициалиазация.
-   `masks`: Скрипт шифрования карты
-   `src/`: Вспомогательные функции для обработки текста.
-   `widget.py`: Скрипт для визуализации отображения номера карты.
-   `requirements.txt`: Список зависимостей.
