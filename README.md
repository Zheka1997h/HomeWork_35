# TaskOne_2 — Управление товарами и категориями

## 📋 Описание проекта

Консольное приложение на Python для управления товарами и категориями с возможностью 
загрузки данных из JSON-файлов. Проект демонстрирует принципы ООП: инкапсуляцию, 
композицию и работу с классами.

## 🛠 Функционал

### Класс `Product` (Товар)
- Хранение информации о товаре: название, описание, цена, количество
- Автоматический подсчёт общего количества созданных товаров (`Product.product_count`)
- Преобразование в словарь и обратно (сериализация/десериализация)
- Строковое представление товара

### Класс `Category` (Категория)
- Хранение информации о категории: название, описание
- Добавление товаров в категорию
- Подсчёт товаров в категории
- Автоматический подсчёт общего количества созданных категорий (`Category.category_count`)
- Преобразование в словарь и обратно

### Класс `Read_Json_file` (Менеджер данных)
- Чтение JSON-файлов с данными о категориях и товарах
- Поддержка двух форматов JSON: словарь с ключом `"categories"` и список категорий
- Обработка ошибок: файл не найден, невалидный JSON, ошибки доступа
- Подсчёт общего количества товаров во всех категориях
